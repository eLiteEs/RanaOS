# User Docs: 3. Basic commands

RanaOS is like MS-DOS or Arch Linux, by default it has a command interface with some commands. In this tutorial you'll learn some of them.

### `help`

This command is almost in every OS, it shows a list of commands with information like what they do or how to use them.

Usage: `help`

### `echo`

This is another command that it's almost in every OS, this comamnd outputs text to the screen.

Usage: `echo [message]`

Replace `[message]` with the actual message, for example `echo hello world!`

### `clear`

This commands clears the screen of the console.

Usage: `clear`

> You can also use `cls` if you come from Windows

### `time`

This command outputs the actual time with the format `HH:MM:SS`.

Usage: `time`

> By using the command `time --set`, you can configure a new time.

### `date`

This command outputs the actual date with the format `DD/MM/YYYY`.

Usage: `date`

### `parrot`

This commands shows a dancing parrot animation in the console, you can stop the animation by pressing `c`.

Usage: `parrot`

### `jogo`

This command starts a very simple game, you can exit the game by pressing any key that isn't the arrow keys because you use them to move.

Usage: `jogo`

### `shutdown`

This command poweroffs the computer showing a confirmation dialog before doing it.

Usage: `shutdown`

> You can use `shutdown /y` for powering off the computer without asking.

> You can also use `shutdwn` and `shutdwn /y` to do the same actions.

### `reboot`

This command reboots the computer also showing a confirmation dialog.

Usage: `reboot`

> You can also use the `reboot /y` command to reboot the computer without confirmation dialog.
